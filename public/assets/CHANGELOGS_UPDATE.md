## TurboCraft Launcher — PC Edition V1.6.0

### Built for Desktop Gamers (Windows, Linux & macOS)

- **1:1 Signature TurboCraft Experience on PC:** Animated `default_background.mp4` video backdrop, real-time `BackgroundGlass` frosted blur, bouncy spring-animated `SideBar`, 3-Column Home Dashboard, Festival Particle Simulations (Fireflies, Snow, Rain, Fireworks, Hearts, Bat Swarm), and all 7 official Material-3 themes (`Verdant Dawn`, `Embermire`, `Velvet Rose`, `Mistwave`, `Glacier`, `VerdantField`, `Urban Ash` + Custom Hex Picker).
- **Native PC Launcher Core:** Full Mojang Version Manifest v2 multi-threaded SHA-1 verified downloader, automatic OS-native LWJGL library extraction, per-instance isolated directories, and real JVM game process launcher with Aikar's G1GC & Generational ZGC presets.
- **Mod Loaders & Modpacks:** One-click installation for **Vanilla, Fabric, Quilt, NeoForge, Forge, and OptiFine**, plus `.mrpack` & CurseForge `.zip` Modpack import and export.
- **Auto Java Runtime Manager:** Automatically detects installed PC JDK/JREs and downloads **Adoptium Temurin Java 8, Java 17, Java 21, and Java 25** inside the launcher.
- **Live 3D Player Pet (`skinview3d`):** Interactive WebGL 3D skin & cape preview with cursor gaze-tracking, Steve/Alex arm models, idle/walk/run/fly animations, tap reactions, and Laby/MinecraftCapes Wardrobe gallery.
- **Cross-Platform Social Hub (Synced with Mobile!):** Powered by the shared TurboCraft Supabase backend — claim your `@handle`, add friends across PC & Android, see live Online/Idle/Offline presence dots, send Direct Messages, host/discover Parties with 6-character codes, and manage Recovery Codes.
- **Terracotta LAN Tunnel & Discord RPC:** Host or join LAN worlds with friends over P2P without port forwarding, and display your live Minecraft instance status on Discord Desktop.
- **Built-in Power Tools:** Smart Crash Log Analyzer + 1-click `mclo.gs` log sharing, Launcher File Explorer + Config Code Editor, Weekly & Daily Playtime Charts, and English / हिन्दी localization.
